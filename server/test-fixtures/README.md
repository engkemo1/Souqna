# اختبارات مودة (كتالوج + سيناريوهات)

- `occasion-catalog.json`: 146 منتج لبس مناسبات ورسمي بنفس شكل صفوف قاعدة البيانات (رجالي، حريمي، محتشم، أطفال، رياضة). كل منتج فيه `expect` (المفتاح والرسمية) تستخدمه الاختبارات فقط. فيه **فخاخ مقصودة**: فساتين قريبة من الأبيض (`near_white`)، "دريس" بدون وصف، جلابية مطرزة، منتج نافد، ومفيش تاكسيدو ولا جاكيت جلد (علشان نختبر حالة "مفيش").
- `scenarios.json`: 29 سيناريو (عامية، فرانكو، إنجليزي، خليط، أخطاء إملائية، أطفال، عيلة، عزاء، جو بارد، صورة). كل واحد فيه الرسالة والنتيجة المتوقعة (فهم + حالة النتيجة + قطع مطلوبة + ممنوعات).

الوقت المحاكى: الاثنين 12 أكتوبر 2026، 7:30 مساءً بتوقيت القاهرة.

لسه مفيش كود بيشغّل السيناريوهات. ده هيتبني مع المحرك (الخطوة الجاية)، وكل سيناريو هيبقى اختبار ينجح أو يفشل.
